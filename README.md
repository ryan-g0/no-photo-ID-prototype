# no-photo-ID-prototype

Experimental design prototype for snake species identification in the absence of a photo.

## What this is
A **design prototype** for exercising the no-photo ID flow. It is not the production system and not the canonical engine.

## Datasets are stand-ins
The files in `datasets/` are **sample/stand-in data only** — not real clinical data, not real contact details. They exist to populate the prototype and are swapped freely. Do not treat any value here as authoritative.

## How to use
Open `index.html` to run the prototype. To try a different dataset, swap the file referenced in `index.html` for another one in `datasets/`.
