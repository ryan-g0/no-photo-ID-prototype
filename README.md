# no-photo-ID-prototype

Experimental design prototype for snake species identification in the absence of a photo.

## What this is
A **design prototype** for exercising the no-photo ID flow. It is not the production system and not the canonical engine.

## How the data works
The species data is generated directly into `index.html` (see the `SPECIES` list in the code). This prototype is produced by prompting Claude to regenerate the page — the data is not loaded from a separate file. To change the dataset, regenerate `index.html` with an updated prompt.

## Stand-in data
The species content here is **sample/stand-in data only** — not real clinical data, and not the canonical Eswatini species set. Do not treat any value here as authoritative.

## How to use
Open `index.html` to run the prototype.
